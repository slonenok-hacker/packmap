# PackMap — утилита для сборки ресурсов GoldSrc-карт (CS 1.6)

PackMap автоматизирует подготовку папки с ресурсами карты (BSP, текстуры, модели, звуки, скайбокс) для раздачи игрокам или загрузки на сервер. Утилита анализирует BSP-файл, собирает все зависимости и формирует структуру папок, а также генерирует файл `.res` для докачки недостающих ресурсов.

## Возможности

- **Автоматическое извлечение зависимостей**: читает энтити из BSP и определяет WAD-текстуры, скайбокс, модели (`.mdl`), спрайты (`.spr`) и звуки (`.wav`).
- **Анализ вшитых текстур**: определяет, какие текстуры уже встроены в BSP (в lump miptex), и не требует внешних WAD для них.
- **Обработка скайбокса**: автоматически ищет и копирует 6 граней скайбокса (`bk`, `ft`, `lf`, `rt`, `up`, `dn`) в формате `.tga` или `.bmp`.
- **Генерация `.res`-файла**: создаёт список ресурсов для докачки клиентом (формат, совместимый с движком GoldSrc).
- **Извлечение вшитых текстур в WAD3**: опция для моддеров, позволяющая выгрузить встроенные текстуры в отдельный WAD-файл для редактирования в Hammer.
- **Два режима работы**: графический интерфейс (GUI) и командная строка (CLI).

## Требования

- Python 3.8 или выше.
- Библиотека `tkinter` (для GUI; в большинстве дистрибутивов Python она встроена).
- Доступ к файлам игры (папка мода, например, `cstrike`, и папка `valve`).
